### 테이블 구성 및 데이터
- 작업지시에 데이터를 입력할 때 개통건(작업구분코드='A')이면 접수번호에 개통접수번호를 입력하고, 장애건(작업구분코드='B')이면 장애접수번호를 입력
### 인덱스 구성
- 작업지시_pk : 작업일련번호
- 작업지시_x1 : 작업구분코드+방문예정일자
- 개통접수_pk : 개통접수번호
- 장애접수_pk : 장애접수번호

### 문제
데이터 모델과 인덱스 구성 하에서 방문예정일자가 오늘인 작업지시 데이터를 모두 출력하는 쿼리를 작성하시오. (NL 조인 기준으로 최적 쿼리를 작성하되, 인덱스 변경 및 힌트 지정은 불가)

### 개선 튜닝1
```
select 작업일련번호, 작업자ID, '개통' 작업구분, 고객번호, 주소
from 작업지시 a, 개통접수 b
where 1=1
  and a.접수번호 = b.개통접수번호
  and a.방문예정일자 = to_char(sysdate,'YYYYMMDD')
  and a.작업구분코드 = 'A'
union all
select 작업일련번호, 작업자ID, '장애' 장애구분, 고객번호, 주소
from 작업지시 a, 장애접수 c
where 1=1
  and a.접수번호 = c.장애접수번호
  and a.방문예정일자 = to_char(sysdate,'YYYYMMDD')
  and a.작업구분코드 = 'B'
```

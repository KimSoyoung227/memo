### 테이블 구성 및 데이터
- 작업지시에 데이터를 입력할 때 개통건(작업구분코드='A')이면 접수번호에 개통접수번호를 입력하고, 장애건(작업구분코드='B')이면 장애접수번호를 입력
### 인덱스 구성
- 작업지시_pk : 작업일련번호
- 개통접수_pk : 개통접수번호
- 장애접수_pk : 장애접수번호

### 문제
데이터 모델에서 접수일자가 오늘인 개통접수 및 장애접수 데이터를 모두 출력하는 SQL을 작성하고, 최적 인덱스를 설계하시오.

- NL 조인 기준으로 최적 쿼리를 작성하되, 힌트 지정은 불가
- 개통접수일시와 장애접수일시의 데이터 타입은 DATE

### 개선 튜닝1
```
-- 인덱스
작업지시_x1 : 접수구분코드
개통접수_x1 : 개통접수번호 + 개통접수일시
장애접수_x1 : 장애접수번호 + 장애접수일시

select 작업일련번호, 작업자ID,
	 '개통' 작업구분,
	 b.고객번호 고객번호, 
	 b.주소 주소
from 작업지시 a, 개통접수 b
where 1=1
  and a.접수번호 = b.개통접수번호
  and b.개통접수일시 >= trunc(sysdate)
  and b.개통접수일시 < trunc(sysdate + 1)
  and 접수구분코드 = 'A'
union all
select 작업일련번호, 작업자ID,
	 '장애' 작업구분,
	 c.고객번호 고객번호, 
	 c.주소 주소
from 작업지시 a, 장애접수 c
where 1=1
  and a.접수번호 = c.장애접수번호
  and c.장애접수일시 >= trunc(sysdate)
  and c.장애접수일시 < trunc(sysdate + 1)
  and 접수구분코드 = 'B'  

```

### 보완할 점1
1. 조회 조건이 개통접수 및 장애접수 테이블에 있고 NL 조인으로 처리해야 유리한 소량의 결과집합이라면, 선택의 여지 없이 UNION ALL이 유리하다. 개통접수 및 장애접수 테이블이 드라이빙 테이블이 되도록 조인 순서를 유도하고, 그에 최적화된 인덱스 구성을 해주면 된다.

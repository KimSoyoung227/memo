### 인덱스 구성
- 장비_pk : 장비번호
- 장비_x1 : 장비구분코드
- 상태변경이력_pk : 장비번호 + 변경일자 + 변경순번

### 문제
데이터 모델에서 장비구분코드가 'A001'인 장비의 최종상태코드와 직전일의(=상태변경이력의 변경일자가 장비의 최종상태변경일자보다 작은) 마지막 상태코드, 변경일자, 변경순번을 출력하는 최적 SQL을 작성하시오.

- 장비구분코드 ='A001'인 장비는 10건
- 결과집합을 장비번호 순으로 정렬
- DBMS는 오라클이며, 12c 이후 버전임

### 개선 튜닝1
```
select a.장비번호, a.장비명, a.최종상태코드, b.직전상태코드, b.직전변경일자, b.직전변경순번
from 장비 a, 상태변경이력 b
where a.장비번호 = b.장비번호
  and a.장비구분코드 = 'A001'
  and (b.변경일자, b.변경순번, b.상태코드) = (select *
									   from (
											select h.변경일자, h.변경순번, h.상태코드
											from 상태변경이력 h
											where h.장비번호 = a.장비번호
											  and h.변경일자 < a.최종상태변경일자
											order by 변경일자 desc, 변경순번 desc
										)
										where rownum <= 1
									)
										
order by a.장비번호;


select a.장비번호, a.장비명, a.최종상태코드, b.직전상태코드, b.직전변경일자, b.직전변경순번
from 장비 a, 상태변경이력 b
where a.장비번호 = b.장비번호
  and a.장비구분코드 = 'A001'
  and b.rowid = (select rid
									   from (
											select h.rowid as rid
											from 상태변경이력 h
											where h.장비번호 = a.장비번호
											  and h.변경일자 < a.최종상태변경일자
											order by 변경일자 desc, 변경순번 desc
										)
										where rownum <= 1
									)
										
order by a.장비번호;
```

### 보완할 점1
1. **상태변경이력 h 에서 상태코드까지 조회하면 테이블 랜덤 엑세스가 발생**한다. 상태변경이력 pk의 컬럼까지만 사용해도 무방하다면 다른 컬럼은 제거하는 것이 좋다. 위 쿼리를 보면 상태코드는 메인쿼리 블록에서도 조회할 수 있으므로 인라인 뷰에서는 상태코드를 빼는 것이 좋다.
